# Assignment 9: Git and GitHub Practical

## Objective
Apply Git and GitHub commands in practical scenarios, create repositories, and understand version control workflows.

## What I Learned

This assignment focused on hands-on practice with Git and GitHub, implementing all the commands and concepts covered in the Git lectures.

### Key Concepts Applied

Based on the Git course content:

1. **Repository Management**
   - Initializing repositories
   - Cloning existing repositories
   - Repository configuration

2. **Basic Git Workflow**
   - Staging files with `git add`
   - Committing changes with `git commit`
   - Viewing status and history

3. **Branching and Merging**
   - Creating branches
   - Switching between branches
   - Merging branches
   - Resolving conflicts

4. **Remote Operations**
   - Adding remotes
   - Pushing to GitHub
   - Pulling changes
   - Fetching updates

5. **Collaboration**
   - Forking repositories
   - Creating pull requests
   - Code review process
   - Issue tracking

### Practical Exercises Completed

- Created local Git repository
- Made multiple commits
- Created and merged branches
- Pushed to GitHub
- Collaborated on shared repository
- Resolved merge conflicts
- Used GitHub features (Issues, PRs)

### Commands Practiced

```bash
# Repository setup
git init
git clone <url>

# Basic workflow
git status
git add .
git commit -m "message"

# Branching
git branch feature-branch
git checkout feature-branch
git merge feature-branch

# Remote operations
git remote add origin <url>
git push origin main
git pull origin main

# History
git log
git log --oneline --graph
```

## Key Takeaways

- Git provides complete version history
- Branching enables parallel development
- GitHub facilitates team collaboration
- Commit messages are important documentation
- Regular commits help track progress
- Merge conflicts are normal and manageable
